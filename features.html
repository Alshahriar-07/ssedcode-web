Features

Everything a terminal-native developer needs

Considered design meets serious engineering — from first launch to your thousandth session.

Five Independent Providers

OpenRouter, FreeModel Claude, FreeModel Codex, AeroLink, and local Ollama — each with its own API key, model, and history. Switch anytime with /provider.

Streaming Responses

Tokens render the instant they arrive — live Markdown and syntax-highlighted code as the answer forms.

Live Model Catalogue

No model is ever hardcoded — pick from each provider's live catalogue, or let FreeModel auto-select the best one with /model auto.

Code Mode

Project-aware coding inside your IDE workflow — work with project files, edit code, and drive development workflows with AI-assisted programming.

Assist Mode · /assist

Desktop and computer control with AI-assisted actions — browser, keyboard, mouse, windows, and vision for tasks beyond code editing.

Agent Tools

Read, edit, search, and run commands in your project — /tools lists capabilities, /index shows the project tree, /permission sets access levels.

Conversation Memory

Session memory with auto-saved history — /history lists saved conversations, /reset starts fresh. History is stored per provider.

Markdown Rendering

Rich Markdown rendered directly in your terminal — headings, lists, tables, links, and highlighted code blocks included.

Windows Installer

One-click seedcode-cli-setup.exe — installs Seed Code, adds seedcode to PATH, creates Start Menu shortcuts. No Python required.

Diagnostics

/doctor checks config, network, and provider health in one pass — with quiet logs at ~/.seedcode/logs/seedcode.log.

Secure by Design

API keys are saved only after real authenticated validation, environment variables override stored keys, and keys or content never reach the logs.

Open Source

MIT licensed and developed in the open. Read the source, file issues, and ship improvements.
