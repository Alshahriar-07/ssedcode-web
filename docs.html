Installation

pip (all platforms)

Requires Python 3.12 or newer. Installs straight from PyPI.

# Install and launch
$ pip install seedcode-cli
$ seedcode

# Verify
$ seedcode --version
seedcode v5.0.2

uv (isolated tool)

$ uv tool install seedcode-cli

Windows installer (recommended)

One-click seedcode-cli-setup.exe — installs to Program Files, adds seedcode to PATH, creates Start Menu shortcuts, no Python required. Download for Windows.

Linux & macOS

Grab the packaged ZIP from MEGA — it includes the complete package for both platforms. Helper scripts live in scripts/linux/ and scripts/macos/. You can also install from the source archive with pip install ..

Tip: whichever method you choose, /doctor inside a session confirms everything is in place.

Configuration

Seed Code stores its settings in a single JSON file at ~/.seedcode/config.json (owner-only permissions where the OS supports it). Each provider keeps its own entry, so nothing is shared or overwritten.

# ~/.seedcode/config.json
{
  "active_provider": "freemodel_claude",
  "providers": {
    "openrouter":        { "api_key": "sk-or-...", "model": "vendor/model" },
    "freemodel_claude":  { "api_key": "fe_oa_...", "model": "claude-sonnet-4-6" },
    "freemodel_codex":   { "api_key": "fe_oa_...", "model": "auto" },
    "aerolink":          { "api_key": "...",       "model": "..." },
    "ollama":            { "api_key": "",          "model": "llama3.2" }
  },
  "ollama_host": "http://localhost:11434",
  "max_tokens": 1024
}

API keys

Keys are only saved after a real authenticated validation. For CI and containers, environment variables override stored keys: OPENROUTER_API_KEY, FREEMODEL_API_KEY, and AEROLINK_API_KEY.

Providers

Five independent backends — each owns its API key, model, connection status, and history. Switch anytime with /provider.

ProviderBest forConfig value
OpenRouterFull model catalogue — free and Pro modes on one keyopenrouter
FreeModel ClaudeClaude-family models, live catalogue, auto-selectfreemodel_claude
FreeModel CodexGPT/Codex models on the Responses APIfreemodel_codex
AeroLinkAnthropic-compatible gateway, dynamic model fetchaerolink
OllamaFully local, private, no API keyollama

No model is ever hardcoded — browse any provider's live catalogue with /model. 312+ models on OpenRouter, 47+ of them free.

Commands

Every command is a slash command, typed inside a seedcode session.

CommandDescription
/helpShow available commands
/providerSwitch provider: OpenRouter, FreeModel Claude, FreeModel Codex, AeroLink, Ollama
/apikeyView, replace, remove, or validate the active key
/modelBrowse the live model list ('auto' = FreeModel auto-select)
/configShow configuration — every provider's key and model
/settingsChange a setting: username, stream, ollama_host, max_tokens
/doctorDiagnose config, network, and provider health
/agentToggle agent mode — the AI can read, edit, search, and run commands
/assistEnable Assist Mode: unified AI + computer control
/permissionSet the agent permission mode: read_only, workspace, full_access
/toolsList the tools available in agent mode
/indexShow a compact tree of the current project
/historyList saved conversation sessions
/resetForget the current conversation
/clearClear the screen
/aboutAbout Seed Code
/versionShow the version
/exitLeave the chat — back to the main menu

Troubleshooting

  • Command not found — make sure your Python scripts directory is on PATH, or reinstall with uv tool install seedcode-cli.
  • Auth errors — re-run the API key flow with /apikey, or set OPENROUTER_API_KEY, FREEMODEL_API_KEY, or AEROLINK_API_KEY.
  • Garbled output — use a terminal with truecolor support (Windows Terminal, iTerm2, most modern emulators).
