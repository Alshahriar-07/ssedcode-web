Capabilities

SeedCode CLI features: Not another chat window.
A working agent.

Seed Code operates inside the workspace you choose. It inspects, plans, edits, executes and checks its work through real tools.

Understands the project

Indexes the selected folder, searches files and reads only the context a task needs. Project memory lives in .seedcode.

Changes actual files

Create, edit, move, copy, rename and delete files with real operation results and bounded diffs.

Runs the commands

Executes commands in the workspace, streams output and records exit codes and duration.

Evidence over claims

Runs tests and checks results. A task is not reported complete just because a model says it is.

Looks up documentation

When a task needs current information, built-in web search and page fetching bring sources into the workflow.

Permission before risk

Dangerous shell commands, deletes, git mutations and writes outside the workspace request approval.

A real task, in real time

The activity view reflects actual backend operations. It does not invent progress or fabricate completed work.
