Command reference

SeedCode CLI commands: One agent.
Full control.

Type a slash at the start of a line to browse commands with descriptions and autocomplete.

CommandWhat it does
/helpShow available commands
/statusShow live runtime status
/providerSelect or manage the active provider
/provider testTest the active connection
/modelBrowse and select a model
/modelsManage model IDs, fallback models and execution profiles
/customManage custom providers
/apikeyView, replace, remove or validate the active key
/workspaceShow or change the active project folder
/permissionShow or set the tool permission level
/sessionShow agent session state and per-task records
/pause /resume /stopPause, resume or stop the running agent session
/memoryShow .seedcode project memory and recent session notes
/indexShow a compact project tree
/filesSearch project files
/toolsList tools available to the coding agent
/agentsList or switch agent profiles
/historyBrowse saved sessions
/doctorDiagnose configuration, network and provider health
/settingsOpen interactive settings
/themePick a colour theme
/paletteOpen command palette
/shortcutsShow keyboard shortcuts
/resetForget current conversation context
/clearClear the screen
/configShow current configuration
/about /versionShow product information and version
/exitLeave the session

Keyboard shortcuts

EnterSend message
Shift+EnterInsert a newline
↑ / ↓Move inside a message or walk history at the edges
Ctrl+CCancel the running turn or clear composer
EscDismiss suggestions or deny a permission prompt
Ctrl+EExpand the last file diff
Ctrl+TExpand the last command output
Ctrl+KOpen command palette
Ctrl+DExit
