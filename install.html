Install SeedCode CLI: Install once.
Build from your terminal.

Choose the installation route for your platform. The remote installers verify release checksums before installing.

Windows · Recommended

PowerShell 5.1 or newer · current user · no administrator rights · Python not required.

irm https://seedcode-cli.vercel.app/install.ps1 | iex

Linux / macOS

curl -fsSL https://seedcode-cli.vercel.app/install.sh | bash

Uses a published standalone binary when available; otherwise installs the official Python wheel. Python 3.10+ and pip/pipx may be required.

First launch

How do I select a project?

Choose Current Folder to work in the directory where you launched Seed Code, or Choose a Folder to browse for another workspace. The selected folder becomes the root for file operations, indexing, memory and terminal commands.

Does the installer verify downloads?

Yes. The remote installers use the release SHA256SUMS.txt as the authoritative checksum source and abort if the checksum is missing, unreachable or does not match.

How do I verify the installation?

Open a new terminal and run seedcode --version. It should report Seed Code CLI 10.2.1.
